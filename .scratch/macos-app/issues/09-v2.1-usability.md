# 09 — v2.1 usability: search, export, offline cache, keyboard

Status: ready-for-human (waiting for the user's manual test)
Type: feature

## Summary

The four gaps from the 2026-10-26 review, landing together in v2.1.0: Search, Export/Copy as Markdown, offline cache (instant start), keyboard navigation + standard menus.

## Delivered

- [x] Search — client-side, case-insensitive over title / summary / Transcript / topics / speakers (`Record.matches`); search field at the top of the sidebar (stacks with the Collection filter); Escape clears and refocuses the list; ⌘F focuses the field via the Edit menu; a Record hidden by the search is dropped from the detail column
- [x] Export — `RecordMarkdown` (per-Record document, combined all-Records file, sanitized file names); "Copy as Markdown" beside "Copy transcript"; File > Export All Records… (⌘E) and Export Selected Record… via NSSavePanel; the menu acts on the frontmost window through `focusedSceneValue` (`RecordCommands`)
- [x] Offline cache — `CachedSnapshot` (Records + Collections + account uuid) persisted after every successful `loadAll`, shown instantly at `bootstrap()` when the uuid matches the signed-in account, wiped on sign-out and session expiry; `RecordCache` uses `millisecondsSince1970` dates so round-trips are exact
- [x] Keyboard — the Record list takes focus on appear (arrow-key navigation); Escape in the search field returns focus to the list
- [x] Tests — RecordMarkdownTests, RecordCacheTests (round-trip, missing/corrupt = no cache), AppModelTests (bootstrap-from-cache, cross-account guard, persist + sign-out wipe, `visibleRecords` combining Collection filter + search), `Record.matches` fixture test — 72/72 green. AppModelTests now inject a temporary cache URL so tests never touch the user's real cache file.

## Comments

- 2026-10-26 — version stays 2.1.0 (Collections + these four land in the same unreleased version). The release tag waits for the user's manual test.
