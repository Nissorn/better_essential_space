# better_essential_space

Reverse engineering Nothing's Essential Space (`com.nothing.ntessentialspace`) to build a native macOS Swift client that logs in with a Nothing account and views Essential Space content.

Layout: `notes/` holds reverse-engineering findings (API, auth, data formats); the macOS app lives in `macos/` once started.
